# Weekly assignments

[Deliverable structure](deliverables_structure.md) explains assignment creation, proposed teams, responsibilities, Co-PM checks and submission. [DELIVERABLES.md](../DELIVERABLES.md) is the semester roadmap. Future GitHub Issues are authoritative for owners, deadlines, status and changes. Week 0 is the PM-approved exception: instructions/deadline in Discord, individual PRs into `deliverable0`, no Issue required.

Each approved week's instructions and supplied assets live together under `weekly/weekN/`. The PM publishes the reviewed starter on `deliverable0` and announces its assignment link/deadline in Discord before Week 0 members start. Future assignments use [assignment-template.md](assignment-template.md) and are added only when approved.
