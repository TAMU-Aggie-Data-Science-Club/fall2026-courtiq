[Deliverable structure](deliverables_strucutre.md) explains assignment creation, proposed teams, responsibilities, Co-PM checks and submission. Week 0 is the PM-approved exception: instructions/deadline in Discord, individual PRs into `deliverable0`, no Issue required.
