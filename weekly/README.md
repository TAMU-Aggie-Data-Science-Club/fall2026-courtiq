# CourtIQ weekly assignments

Use this directory for detailed weekly assignments, learning resources, setup, submission requirements and acceptance criteria. [DELIVERABLES.md](../DELIVERABLES.md) remains the high-level semester roadmap.

**Individual GitHub Issues are authoritative for owners, task status, deadlines and approved changes.** Read an assignment's linked issue before starting. This index is a navigation aid; it does not maintain a separate ownership or progress tracker. Assignment checklists describe acceptance criteria, not current completion status.

## Adding an approved weekly assignment

1. Copy [assignment-template.md](assignment-template.md) to `week-NN-short-title.md`, using the approved week number and title. The template is a blank format, not a scheduled assignment.
2. Fill in the approved goal, learning objectives, scope, resources, setup, tasks, artifacts and acceptance criteria. Link the applicable GitHub Issue(s); keep owners, live status and changes in those issues.
3. Follow [CONTRIBUTING.md](../CONTRIBUTING.md): work on an issue feature branch and open its PR into the issue's integration branch. Add one index row when the assignment is approved. Update the semester roadmap only if a milestone is added, split or resequenced.
4. Record approved changes in the issue and update the corresponding instructions so they stay consistent. Do not create future assignments merely to fill the calendar.
